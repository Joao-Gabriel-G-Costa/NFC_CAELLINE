# Cartão NFC — Caelline Costa Jardim

Site estático responsivo para GitHub Pages. Não precisa instalar dependências.

## Arquivos
- `index.html` — conteúdo e links
- `style.css` — visual e responsividade
- `assets/logo-original.jpeg` — logomarca original, sem edição
- `assets/caelline.jpeg` — foto profissional original

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie todos os arquivos e a pasta `assets` para a raiz do repositório.
3. Em **Settings > Pages**, selecione **Deploy from a branch**, branch **main**, pasta **/(root)** e salve.
4. Aguarde o GitHub disponibilizar o endereço do site. Grave esse endereço no cartão NFC.

O site não inclui QR Code. WhatsApp, Instagram e e-mail são links clicáveis.
